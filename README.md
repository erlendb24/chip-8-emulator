# chip-8-emulator
Chip-8 emulator in C using raylib 5.5. 

Breakout ROM found in assets is credited to David Winter, 1997

Tic-Tac-Toe ROM found in assets is credited to David Winter

Tetris ROM found in assets is credited to David Winter, 1991

## How to run a program

```./chip assets/[game].ch8```

## Keyboard mappings

Use 1-4, Q-R, A-F and Z-F to control games.

## Game controls

Breakout uses W and E, Tetris uses Q, W, E and A and Tic-Tac-Toe represents  
the board with 1-3 being the upper row, Q-E being the middle and Z-C being  
the lower row.
